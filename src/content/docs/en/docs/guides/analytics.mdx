**Analytics** aggregates real gateway calls. Check the time window, business timezone and currency before comparing volume, usage, user charges and supplier cost.

| View | Useful question |
|---|---|
| Model usage | Which models account for most usage and cost? |
| Provider usage | Which upstreams receive traffic and incur costs? |
| User usage | Which members or customers consume quota? |
| Reliability | Where are failures, first-token delays and upstream waits concentrated? |

## From a trend to a request

1. Choose time and dimensions; distinguish missing samples from zero values.
2. Compare success, first-token timing, upstream latency and cache metrics rather than final success alone.
3. Open [request logs](/en/docs/guides/request-logs/) for the affected model, provider or user and inspect attempt failures.
4. Decide whether to change priorities, weights, Sticky, fallback accounts or user quotas.

The time range is restored from the page address, so a view can be revisited or shared. Drilling from usage into logs keeps your filters, and historical activity locates logs by request ID.

Direct Playground probes do not write user request logs or enter this user usage data. Use request snapshots and account audit for precise reconciliation.
