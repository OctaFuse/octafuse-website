Use **Config** to maintain global defaults. Model and route rules may override specific settings according to their precedence.

| Setting | Effect |
|---|---|
| Business timezone | Price windows, business-day usage, resets and Admin time display |
| Billing currency | Interpretation of model/tool prices, charges and statistics |
| Global routing strategy | Default candidate selection when no more specific rule applies |
| User factor composition | `multiply` combines factors; `min` chooses the smaller route/user factor |
| Alert webhooks | Notifications for supported events |

## Before and after a change

1. Review the card's scope and the effect of currency and timezone on existing data.
2. Save or discard each card independently; check unsaved indicators.
3. Verify with new requests, price previews and logs. Old requests keep their recorded pricing snapshots.
