Use **System → Config** to maintain global defaults. The page is split into General, Routing & billing, Notifications and Maintenance mode sections. Model and route rules may override specific settings according to their precedence.

| Setting (section) | Effect |
|---|---|
| Business timezone (General) | Price windows, business-day usage, resets and Admin time display |
| Billing currency (General) | Interpretation of model/tool prices, charges and statistics |
| Global routing strategy (Routing & billing) | Default candidate selection when no more specific rule applies |
| User factor composition (Routing & billing) | `multiply` combines factors; `min` chooses the smaller route/user factor |
| Alert webhooks (Notifications) | Notifications for supported events |

## Before and after a change

1. Review the card's scope and the effect of currency and timezone on existing data.
2. Save or discard each card independently; check unsaved indicators.
3. Verify with new requests, price previews and logs. Old requests keep their recorded pricing snapshots.

![Independent configuration card saving](/screenshots/v2-14-0-config-unsaved.webp)

Maintenance windows are controlled in this page's Maintenance mode section (see [Maintenance](/en/docs/deploy/maintenance/)). Admin credentials live under System → Integration Keys ([Integration Keys](/en/docs/guides/integration/)). The MCP authorization server is configured on the MCP Servers page ([MCP OAuth](/en/docs/guides/oauth/)).
