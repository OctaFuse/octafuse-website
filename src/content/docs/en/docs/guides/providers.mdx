One **Provider** record represents one upstream account: protocol endpoints, one credential and activation state. Use separate records for multiple accounts on the same platform, then place them in route pools.

## Import and connect

1. Choose a pay-as-you-go, Coding / Token Plan or private-compatible template from the [catalog](/en/catalog/providers/). Do not mix plan-specific and ordinary endpoints.
2. Supply credentials and replace project, region or resource placeholders. API keys and Vertex AI service-account JSON are different credential types.
3. Configure the OpenAI, Anthropic, Gemini, DashScope, MiniMax, Volcengine or ElevenLabs endpoints needed by the workload.
4. Use a Base URL only when the upstream implements the relevant capabilities. Use individual endpoints for partial support.
5. Configure [models and routes](/en/docs/guides/routing/), test the target in Playground, then verify a real Proxy call.

## Review official template updates

Administrators manually trigger **Sync** on the Providers page; it compares first and applies only after you confirm. Compare changed descriptions and endpoints field by field, choose official or local values, and inspect affected routes before applying. Importing a newer catalog does not overwrite account credentials and existing configuration automatically.

Review model changes separately under [Models](/en/docs/guides/models/). See [provider quotas](/en/docs/guides/provider-quotas/) for balances and subscription windows.

## Gemini and Vertex AI

Gemini supports query-key and Bearer authentication. Project-scoped Vertex AI exchanges service-account credentials for an access token. Replace project and region placeholders and provide the complete service-account JSON required by that template.

Native Gemini content generation uses a unified `models.generate` template; the runtime chooses streaming or non-streaming actions. See the [configuration reference](https://github.com/OctaFuse/octafuse-gateway/blob/v2.19.0/docs/users/configuration.md) for exact authentication and URL rules.

## Maintenance

Test connectivity after changing a credential, endpoint or region. Inspect related routes before deleting a provider. Confirmed route deletions apply immediately and are not undone by closing the form. An account does not necessarily provide every model or operation.
