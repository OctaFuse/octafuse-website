In Admin, open **Inference → Providers**. A **Provider** represents one upstream service account with protocol endpoints, one upstream API key, and an enabled status. Cards show key status, active route counts, and protocol capabilities, with filters for status and OpenAI, Anthropic, Gemini, or DashScope support.

<Aside type="tip" title="Prerequisite">
	Finish [Quick start](/en/docs/quick-start/) so you can sign in to Admin.
</Aside>

## What to do in Admin

<Steps>
1. In the sidebar under **Inference**, open **Providers**.
1. **Create or edit**: set the display name, one **API Key**, status, and optional notes, then configure Base URLs or capability endpoints on each protocol tab. OpenAI Responses can use an explicit endpoint or derive `/v1/responses` from the OpenAI Base URL.
1. **Multiple accounts**: create one Provider per vendor account, then add multiple Upstream Targets to the same Route Pool. Configure priority, weight, and distribution strategy under [Routing](/en/docs/guides/routing/).
1. **Import from catalog**: use the built-in catalog to pre-fill endpoints; you still need a valid **API Key**. For Responses or Images, confirm the matching capability appears on the card.
1. After saving, go to [Routing](/en/docs/guides/routing/) to bind models to this vendor and protocol; use [Playground](/en/docs/features/playground/) or [Simulator](/en/docs/features/simulator/) to validate connectivity.
</Steps>

## Gemini Generate Content

For standard Gemini services, set the Base URL to the path immediately before `{model}`, for example `https://generativelanguage.googleapis.com/v1beta/models`. For a non-standard upstream, use one Advanced **`models.generate`** template such as `https://example.com/v1beta/models/{model}:{action}`; `{action}` resolves to `generateContent` or `streamGenerateContent` at runtime. Legacy per-action templates remain readable, but new configuration should use the unified template.

## Notes

- Wrong base URLs / endpoints often show up as 404/401 — double-check upstream docs.
- This screen **does not** include a one-click connectivity test; validate via routes + Playground / Simulator.
- When the upstream rotates a key, replace it here. Use multiple Providers and Route Targets for gradual cutover or backup accounts.

## Automation

For bulk changes from your backend, use the admin HTTP API — see the [GitHub technical reference](/en/docs/github-reference/).
