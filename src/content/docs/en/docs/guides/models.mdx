Open **Inference → Models**. **Models** are catalog entries: the client **`model`** string is resolved here first, then [Routing](/en/docs/guides/routing/) picks the upstream path. You can create, edit, import presets, and edit tiered pricing; the list surfaces how routes are attached to each model.

<Aside type="tip" title="Prerequisite">
	Configure at least one [Provider](/en/docs/guides/providers/) first.
</Aside>

## What to do in Admin

<Steps>
1. Open **Models**.
1. **Create or edit**: set the **model id** clients and routes will use, **display name**, **vendor**, and other form fields (context limits, etc.).
1. **Import from catalog**: bulk pre-fill from the built-in catalog, then review and save.
1. **Pricing**: use the tier editor in the page (currency display follows your global billing currency setting).
1. After saving, add at least one **active** route in [Routing](/en/docs/guides/routing/) or clients cannot resolve the model.
1. **Capabilities and billing mode**: for Images, verify `image_billing_mode` (token / per_image); for transcription, verify `audio_billing_mode` (token / per_second). Default `hash_affinity` routing keeps a stable preferred Provider at protocol granularity.
</Steps>

<Aside type="note" title="Gemini 3.1 Flash-Lite model ID">
	The built-in preset now uses `gemini-3.1-flash-lite` instead of `gemini-3.1-flash-lite-preview`. The model remains in preview. Static presets do not overwrite imported rows; delete and re-import or edit the model ID manually.
</Aside>

## How clients pass `model`

Use the **base model id**, or **`baseModelId:routeGroup`** (for example `my-model:free`). The route group must match what you configured in Admin. Protocol details: [GitHub technical reference](/en/docs/github-reference/).

## `/v1/models` vs `/catalog/models`

| Endpoint | Auth | Typical use |
|----------|------|-------------|
| **`GET /v1/models`** | User `sk-…` | Agents / SDKs; LLMs by default (`kind=image` / `kind=audio` / `kind=all` when needed) |
| **`GET /catalog/models`** | None | Public portal discovery; protocols and route groups from active routes |

They are not the same response shape — do not mix them. Image pricing: [Image generation / edit](/en/docs/guides/images/).
