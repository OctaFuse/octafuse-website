**REST Services** exposes independent tool APIs under `/v1/tools/*`. They are separate from model conversation protocols: the client executes these requests after a model asks to use a tool.

| Service | Endpoint | Implemented engine examples |
|---|---|---|
| Web search | `/v1/tools/web-search` | Bocha, Tavily, CleverSee, Tencent WSA, DeepSeek |
| Web fetch | `/v1/tools/web-fetch` | Firecrawl, Tavily Extract, Jina Reader, DeepSeek |
| Deep search | `/v1/tools/web-deep-search` | Firecrawl Search, Jina Search, DeepSeek |
| AI detection | `/v1/tools/ai-detection` | Tencent TMS |

## Configure and activate

1. Open REST Services under the Tools group. Filter by name, service type or status, then open a service workspace.
2. In Providers & pricing, expand a provider to read its notes, then use Configure to enter credentials and pricing and save. Unsaved edits can be reverted.
3. Set Standard price, Charged factor and Metered factor; check the price preview. Search bills per request; AI detection uses configured character units.
4. Activate the intended provider in the Usage column of the provider list. Each tool has one Active engine; providers with unsaved edits or incomplete credentials cannot be activated.
5. Call Proxy with a user key, then review the result in Request logs: choose the REST tool in the Type filter, and the detail shows the engine, request parameters, results and accounting.

A zero Charged factor makes user calls free while retaining supplier cost. Model route schedules and per-model user discounts do not apply. Legacy independent unit prices remain readable; newly saved rules use a base price and factors.

## Use the DeepSeek engine

The DeepSeek engine connects to DeepSeek's standalone Search and Fetch APIs. Each of the three services is configured separately with a DeepSeek API key (it can be the same key), and the public endpoints do not change. Before enabling it:

- Queries are limited to 128 characters; the Gateway truncates longer queries.
- Domain allow and block lists are sent as `site:` / `-site:` when they fit in the query; otherwise the Gateway fetches more results and filters locally.
- Deep search returns page content in a single request.
- The upstream list price is $0.75 per 1,000 successful requests. Set your own Standard price and factors; the Gateway still charges per call for empty results.

## Test a search

```bash
curl -sS http://localhost:8787/v1/tools/web-search \
  -H 'Authorization: Bearer sk-your-api-key' \
  -H 'Content-Type: application/json' \
  -d '{"query":"OctaFuse gateway","count":5}'
```

Upstream failures are not charged. Calls require a usable Active engine. Read [MCP servers](/en/docs/guides/mcp/) to connect external standardized tool services; REST tools are not automatically exposed as MCP.

See the [tool API reference](https://github.com/OctaFuse/octafuse-gateway/blob/v2.21.0/docs/developers/api/user.md) for fields and engine limitations.
