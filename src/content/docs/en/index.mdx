**Bring AI services behind one controlled entry point.** OctaFuse manages model and tool access, routing, user quotas and request records. Applications use a gateway URL and user key; provider configuration, fallback routes, pricing and access controls live in Admin.

## What you can do

<CardGrid>
  <Card title="Connect models and tools" icon="puzzle">Use the appropriate protocols for chat, Responses, images, speech and embeddings. Manage REST tools and remote MCP servers, with optional OAuth for MCP clients.</Card>
  <Card title="Keep requests moving" icon="random">Distribute requests with priorities, weights and four routing strategies. Provider Sticky remembers successful upstreams; failover and circuit breakers handle unavailable targets.</Card>
  <Card title="Give users clear quotas" icon="padlock">Manage periodic budgets and permanent wallet credit separately. Apply user and key rate limits, model and route-group discounts, and separate supplier cost, standard price and user charges.</Card>
  <Card title="Understand each request" icon="magnifier">Follow entry, routing, upstream attempts, response and accounting on a request timeline. Use usage, cost, cache and reliability views to improve configuration.</Card>
  <Card title="Connect another service" icon="laptop">Model IDs, protocol surfaces and explicit adapters control upstream differences. Import presets, then review official model and provider changes field by field.</Card>
  <Card title="Run it in your environment" icon="rocket">Choose Docker with Postgres / MySQL, or Cloudflare Workers with D1. Integrate a product backend through Admin APIs to provision users, issue keys and add credit.</Card>
</CardGrid>

## Choose a use case

- **Personal tooling**: configure models and tools for IDEs, CLIs and scripts, with backup upstreams.
- **Teams and AI applications**: issue separate credentials and manage quotas, rate limits and usage.
- **Agents and tool platforms**: connect REST engines and remote MCP servers, review catalogs and price calls.
- **Product portals and API services**: provision users, distribute quotas, set discounts and read usage through Admin APIs.
