先选择要完成的任务。本版指南以 **Gateway v2.19.0** 为基线；模型与供应商目录也标注其来源版本。API、迁移和架构细节以 [GitHub 技术参考](/zh/docs/github-reference/) 为准。

## 从哪里开始

| 你的目标 | 推荐路径 |
|---|---|
| 先跑通一次模型调用 | [快速开始](/zh/docs/quick-start/) → [接入客户端](/zh/docs/guides/clients/) |
| 接入图片、音频或向量 | [支持能力](/zh/docs/capabilities/) → 对应的多模态指南 |
| 给 Agent 提供工具 | [REST 服务](/zh/docs/guides/tools/)或[MCP 服务](/zh/docs/guides/mcp/)，需要登录授权时阅读 [OAuth](/zh/docs/guides/oauth/) |
| 为团队或客户管理用量 | [用户](/zh/docs/guides/users/) → [额度与计费](/zh/docs/guides/billing/) → [密钥与限流](/zh/docs/guides/api-keys/) |
| 将网关接进业务平台 | [系统集成](/zh/docs/guides/integration/)，从服务端使用具名集成密钥 |
| 上线、升级或处理故障 | [部署选择](/zh/docs/deploy/overview/) → [升级与迁移](/zh/docs/deploy/upgrades/) → [请求流程](/zh/docs/guides/request-logs/) |

## 最短配置路径

**供应商 → 模型 → 路由 → 用户与密钥 → 一次真实调用**。

先用调试台确认上游连通，再用模拟器核对完整的鉴权、选路、扣费和日志。图片、音频、向量和工具按业务需要配置，不是文本调用的前置步骤。

![请求流程从入站、路由、上游尝试到响应和记账](/screenshots/v2-18-0-request-detail-failover.png)

请求失败或变慢时，沿着[请求日志中的流程与时间线](/zh/docs/guides/request-logs/)定位，再结合[用量与可靠性分析](/zh/docs/guides/analytics/)判断是否需要调整路由。

## 三种目录不要混用

- [官网模型与供应商目录](/zh/catalog/models/)：正式版本内置的静态导入预设，不包含你的真实凭证与部署配置。
- 你的网关 `GET /catalog/models`：按已启用路由发现对外能力，无需用户密钥。
- 你的网关 `GET /v1/models`：使用用户密钥，面向客户端发现模型；可按类型筛选。

版本变化阅读[动态](/zh/updates/)；日常操作优先使用本指南。
