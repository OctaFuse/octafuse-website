OctaFuse 是可自托管的 AI 能力网关与运营控制面。文档按工作流组织：先跑起来，再配置供应商、模型、图片生成、智能体工具（Agent Tools）、路由和密钥；需要联调时使用调试台（Playground）、模拟器（Simulator）和日志；需要 API、迁移、架构细节时回到 gateway 仓库的权威技术参考。

<Aside type="tip" title="推荐阅读顺序">
	快速开始 → 供应商（Providers）→ 模型（Models）→ 路由（Routes）→ 智能体工具 → 用户（Users）→ API 密钥（API Keys）→ 模拟器 → 部署。需要字段、SQL、架构或排障细节时，再打开 GitHub 技术参考。
</Aside>
