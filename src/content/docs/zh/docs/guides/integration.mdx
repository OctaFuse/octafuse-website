集成时区分两条链路：应用使用用户凭证调用 **Proxy**；业务服务端使用具名集成密钥调用 **Admin API**，维护用户、密钥、额度与配置。

## 地址与凭证

| 常见环境变量 | 用途 |
|---|---|
| `GATEWAY_URL` | Proxy 根地址，用于模型与工具调用 |
| `GATEWAY_MASTER_URL` | Admin 根地址，服务端在其下调用 `/api/admin/*` |
| `GATEWAY_MASTER_KEY` | 具名 Admin 集成密钥；变量名沿用历史约定，不表示使用旧的共享 Master Key |

在系统 → 集成密钥（Integration Keys）中，为不同业务创建最小权限密钥。它们只放在受信任服务端，不作为浏览器或普通 SDK 的模型调用密钥。

## 常见业务流程

1. 业务注册或开通完成，用外部系统与用户编号幂等解析网关用户。
2. 设置周期套餐，或使用永久额度加额接口发放购买额度；每笔加额传唯一业务引用。
3. 创建对应用户调用密钥，按信任边界交付或保存在服务端。
4. 应用通过 Proxy 调用；平台通过管理接口读取用量与审计信息。
5. 需要用户模型折扣时，支持按模型和分组配置，并保持与全局合成模式一致。

模型公开目录、用户模型列表与官网预设目录的区别见[模型指南](/zh/docs/guides/models/)。MCP 登录接入需额外完成[授权服务器对接](/zh/docs/guides/oauth/)。

## 升级老集成

确认具名集成密钥已替换历史 `legacy-master` 后，再按实际迁移计划轮换或吊销旧密钥。周期额度和永久额度分开管理，不要继续用累加周期预算的方式充值。

接口字段和幂等规则以 [系统集成参考](https://github.com/OctaFuse/octafuse-gateway/blob/v2.19.0/docs/developers/integration.md) 与 [Admin API](https://github.com/OctaFuse/octafuse-gateway/blob/v2.19.0/docs/developers/api/admin.md) 为准。
