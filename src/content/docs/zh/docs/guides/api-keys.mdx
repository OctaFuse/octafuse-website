在 API 密钥（API Keys）页为用户创建调用凭证。客户端以 `Authorization: Bearer sk-…` 请求代理服务；供应商密钥留在网关，管理 API 使用另一类具名集成密钥。

## 发放和回收

1. 选择已有用户，或通过外部身份解析对应用户。
2. 设置可识别的密钥名称，创建后按界面提示保存完整密钥。
3. 使用用户密钥调用 `GET /v1/me` 验证归属和额度。
4. 按应用分别发 Key；不再使用时停用、吊销或删除，不长期共用同一把密钥。

## 两层每分钟请求限制

用户和密钥可以分别设置每分钟请求限制。两层均需满足；多个密钥不能绕过用户级上限。额度不足与速率超限是不同问题：前者检查额度池，后者需降低频率或等待后重试。

模型列表和用户额度查询不消耗用户/密钥 RPM，可用于错误后的只读诊断。具体计数入口与返回字段见 [用户 API](https://github.com/OctaFuse/octafuse-gateway/blob/v2.18.0/docs/developers/api/user.md)。

## 四种凭证的用途

| 凭证 | 保存或使用位置 |
|---|---|
| 上游供应商凭证 | 供应商配置，用于网关请求上游 |
| 用户 `sk-…` | 客户端请求 Proxy，费用归属用户 |
| MCP `oat_…` | OAuth 客户端访问 MCP，仅限 MCP 作用域 |
| Admin 集成密钥 | 受信任服务端调用管理接口，按最小权限分发 |
