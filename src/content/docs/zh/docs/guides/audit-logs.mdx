审计日志（Audit Logs）侧重用户、密钥与额度事件。它与[请求日志](/zh/docs/guides/request-logs/)配合使用，不是所有供应商和路由编辑操作的完整配置审计。

## 从事件定位问题

1. 选择时间范围、事件类型、来源、原因和操作者；必要时填写用户邮箱、Actor ID 或关联 ID。
2. 区分周期额度扣减、永久额度扣减与加额、周期重置及用户/密钥生命周期。
3. 展开记录查看账户快照差异和变更原因。
4. 用关联请求 ID 回到调用流程，核对实际费用；充值问题从用户的加额流水追查业务引用。

![账户审计组合筛选](/screenshots/v2-10-0-audit-log-filters.webp)

## 周期与永久额度分别对账

同一次请求可能同时消耗两种额度，按各自变化核对。永久加额应关联唯一业务流水，周期重置不应被解释为永久余额清空。

账户含义见[额度与计费](/zh/docs/guides/billing/)，事件定义见 [账户审计参考](https://github.com/OctaFuse/octafuse-gateway/blob/v2.18.0/docs/developers/reference/user-audit-logs.md)。
