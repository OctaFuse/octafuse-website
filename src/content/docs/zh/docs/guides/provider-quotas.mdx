供应商额度查询帮助判断上游账号是否还有可用资源。它不修改网关用户额度，也不能代替一次真实请求的连通性验证。

## 查看与刷新

1. 打开供应商页，选择已配置凭证的账号。
2. 对支持查询的类型查看余额、套餐窗口、已用量、重置时间及最近检查结果。
3. 需要更新时执行额度检查；遇到查询失败，核对账号类型、凭证、上游接口和检查时间。
4. 将结果与请求错误和可靠性视图结合，决定是否调整备用上游。

![供应商余额与套餐窗口](/screenshots/v2-12-0-provider-quota.webp)

## 如何解读

普通按量账号可能显示货币余额；Coding / Token Plan 可能显示 5 小时、每周或其他订阅窗口。窗口和单位以该供应商接口实际返回为准，不同平台不能直接横向相加。

部分平台需要与推理 Key 不同的管理凭证，或没有稳定的查询接口；未展示余额不代表不可调用。反过来，额度查询成功也不保证每个模型都已获授权。

额度支持范围与网关版本有关；更新后核对所选版本和账号类型的实际查询结果。

上游账户配置见[供应商](/zh/docs/guides/providers/)，用户消费额度见[额度与计费](/zh/docs/guides/billing/)。支持的查询类型以 [管理 API](https://github.com/OctaFuse/octafuse-gateway/blob/v2.18.0/docs/developers/api/admin.md) 和对应版本的实现为准。
