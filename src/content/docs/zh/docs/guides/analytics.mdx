分析（Analytics）把真实网关调用汇总成运营视图。先确认时间窗口、业务时区和币种，再比较请求量、用量、用户费用与供应成本。

| 视图 | 适合回答的问题 |
|---|---|
| 模型用量 | 哪些模型产生主要用量与成本？ |
| 供应商用量 | 流量和成本实际分配到哪些上游？ |
| 用户用量 | 哪些成员或客户消耗了额度？ |
| 可靠性 | 失败、首 Token 和上游延迟集中在哪里？ |

## 从趋势回到请求

1. 选择时间与目标维度，注意无样本与零值的区别。
2. 同时比较成功率、首 Token、上游耗时和缓存相关指标，避免只根据最终成功率判断体验。
3. 找到异常模型、供应商或用户后，转到[请求日志](/zh/docs/guides/request-logs/)查看具体尝试和失败原因。
4. 再决定是否调整优先级、权重、粘性、备用账号或用户额度。
