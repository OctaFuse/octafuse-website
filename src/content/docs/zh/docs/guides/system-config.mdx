在系统配置（Config）中维护全局默认值。模型和路由可以按其覆盖规则继续覆盖部分默认设置。

| 配置 | 影响 |
|---|---|
| 业务时区 | 价格窗口、用量业务日界、周期重置与后台时间展示 |
| 计费币种 | 目录价、工具单价、费用与统计的解释口径 |
| 全局路由策略 | 未被更具体规则覆盖时的默认选路方式 |
| 用户倍率合成模式 | `multiply` 相乘，或 `min` 取路由与用户倍率中的较小值 |
| 告警 Webhook | 按已支持事件对接通知渠道 |

## 修改前后核对

1. 阅读卡片作用范围，确认币种与时区适合当前业务数据。
2. 每张卡片独立保存或撤销，检查未保存提示。
3. 使用新请求确认路由、价格预览与日志结果；旧请求仍使用当时的计价快照。

![系统配置卡片独立保存与未保存提示](/screenshots/v2-14-0-config-unsaved.webp)
