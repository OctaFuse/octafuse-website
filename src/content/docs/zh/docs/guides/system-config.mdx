在左侧系统（**System**）下打开配置（**Config**）页面。此处集中维护影响全站行为的参数，例如：

- **业务时区**、**计费币种**：影响列表与统计中的时间、金额展示口径；业务时区同时用于路由每日时段（**Daily schedule**）调价的窗口判定。
- **全局路由策略**：`ROUTE_STRATEGY` 可设为 `hash_affinity`（默认）、`weighted_random`、`weight_priority` 或 `weighted_round_robin`；模型规则、路由池默认策略和 `priority` 层策略可继续覆盖。
- **告警 Webhook**（如飞书、企业微信）：可选，用于对接事件通知。
- **自定义键值**：高级场景下可新增其他全局配置项（键名与含义请与运维约定一致）。

敏感内容支持在界面上 **显示 / 隐藏** 切换，便于投屏演示时脱敏。

<Aside type="note" title="集成密钥已独立管理">
	Admin API Key 不再保存在系统配置中。请在 **系统集成 → 集成密钥（Integration Keys）** 为不同系统和使用场景创建具名、最小权限密钥，详见[系统集成](/zh/docs/guides/integration/)。
</Aside>

## 在管理台里要做什么

<Steps>
1. 打开系统配置（**Config**）。
1. 核对业务时区、计费币种是否符合组织规范。
1. 在全局路由策略（**Global route strategy**）卡片中点击**修改（Change）**，选择未被模型或路由池覆盖时使用的默认策略。
1. 按需配置或轮换告警地址。
1. 若有约定好的其他全局项，通过**添加（Add）**（或等效入口）新增并保存。
</Steps>
