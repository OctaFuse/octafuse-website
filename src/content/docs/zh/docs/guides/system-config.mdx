在系统 → 配置（Config）中维护全局默认值，页面分为「基础设置」「路由与计费」「通知」和「维护模式」四个分区。模型和路由可以按其覆盖规则继续覆盖部分默认设置。

| 配置（分区） | 影响 |
|---|---|
| 业务时区（基础设置） | 价格窗口、用量业务日界、周期重置与后台时间展示 |
| 计费币种（基础设置） | 目录价、工具单价、费用与统计的解释口径 |
| 全局路由策略（路由与计费） | 未被更具体规则覆盖时的默认选路方式 |
| 用户倍率合成模式（路由与计费） | `multiply` 相乘，或 `min` 取路由与用户倍率中的较小值 |
| 告警 Webhook（通知） | 按已支持事件对接通知渠道 |

## 修改前后核对

1. 阅读卡片作用范围，确认币种与时区适合当前业务数据。
2. 每张卡片独立保存或撤销，检查未保存提示。
3. 使用新请求确认路由、价格预览与日志结果；旧请求仍使用当时的计价快照。
