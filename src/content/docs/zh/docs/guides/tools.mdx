REST 服务（REST Services）通过 `/v1/tools/*` 为应用和 Agent 提供独立工具 API。它们不是模型对话协议的一部分；模型产生工具调用后，由客户端执行对应工具请求。

| 服务 | 入口 | 已实现引擎示例 |
|---|---|---|
| 网页搜索 | `/v1/tools/web-search` | 博查、Tavily、CleverSee、腾讯云 WSA |
| 网页抓取 | `/v1/tools/web-fetch` | Firecrawl、Tavily Extract、Jina Reader |
| 深度搜索 | `/v1/tools/web-deep-search` | Firecrawl Search、Jina Search |
| AI 率检测 | `/v1/tools/ai-detection` | 腾讯云 TMS |

## 配置与启用

1. 在智能体工具下打开 REST 服务，按名称、服务类型或状态筛选。
2. 点击服务，在弹窗中集中维护第三方凭证、启用状态、计费规则与测试；保存只提交当前服务，未保存的修改可以还原。
3. 设置标准价、用户倍率与供应倍率，核对收费和成本预览。搜索按请求计费，AI 检测按配置的字符单元计费。
4. 保存后启用所需引擎。每种工具当前只有一个活跃引擎，未实现或凭证不全的引擎不可启用。
5. 用用户密钥调用真实代理入口，再到工具调用记录或请求日志查看结果。

用户倍率设为 `0` 时用户免费，仍记录供应成本。REST 服务不应用模型路由时段或用户模型折扣；旧独立单价配置兼容读取，新保存规则使用标准价与倍率。

## 一次搜索请求

```bash
curl -sS http://localhost:8787/v1/tools/web-search \
  -H 'Authorization: Bearer sk-your-api-key' \
  -H 'Content-Type: application/json' \
  -d '{"query":"OctaFuse gateway","count":5}'
```

上游失败不扣用户额度；未配置可用活跃引擎时，调用不能成功。想接入外部标准化工具协议，阅读 [MCP 服务](/zh/docs/guides/mcp/)；REST 工具不会自动作为 MCP 暴露。

各服务字段与引擎限制见 [工具 API 参考](https://github.com/OctaFuse/octafuse-gateway/blob/v2.19.0/docs/developers/api/user.md)。
