在用户（Users）中创建网关账户。用户是额度、计费和限流的主体；API 密钥归属于用户。多个密钥共享所属用户的额度，不会因增加密钥自动获得更多额度。

## 创建与日常维护

1. 按成员、项目或客户创建独立用户，填写邮箱和状态。对接业务平台时可填写外部系统和用户编号。
2. 在「额度与计费」中配置周期额度、重置周期及永久额度；具体规则见[额度、价格与折扣](/zh/docs/guides/billing/)。
3. 按需要为模型或模型的路由组设置用户倍率。保存后可在模型列表中预览用户可见的模型及折扣。
4. 创建或管理该用户的 [API 密钥](/zh/docs/guides/api-keys/)。
5. 从活动记录、请求日志或审计日志追踪调用和额度变化。

## 两种额度分开维护

套餐额度与永久加购余额有各自的用途。日常充值使用永久额度加额接口并传唯一流水号，避免订单重试重复加额。不要用修改周期预算代替充值。

用户编辑页修改的是配置。核对消费变化时以实时日志和额度记录为准；修改周期配置不表示清空已有消费。

## 用户、密钥和 OAuth 应用

同一用户可拥有多个调用密钥。MCP OAuth 应用通过独立访问令牌调用，费用仍计入该用户；可在用户详情查看并撤销授权。OAuth 的接入条件见[授权指南](/zh/docs/guides/oauth/)。
