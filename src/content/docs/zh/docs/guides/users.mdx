在左侧**用户（User）→ 用户（Users）**打开用户列表。**用户**是网关内的账户主体：用于挂载 API 密钥、承载**预算与结算周期**，并出现在请求与审计相关视图中。支持填写邮箱、可选的外部系统标识，以及预算相关字段。

用户**详情页**（点击列表中的用户进入）包含预算计划、关联的 API 密钥（API Keys）、外部身份，以及按模型设置的用户计费倍率（Charged cost factors）。

## 在管理台里要做什么

<Steps>
1. 在**用户**列表中按邮箱、外部身份、状态等条件筛选；列表会展示已消费 / 预算上限进度、下次重置时间、可用密钥数量和模型倍率摘要。
1. **新建用户**：在表单中填写邮箱、可选的外部系统与用户编号、预算上限 / 基准、结算周期等；可按需填写 `metadata`（一般为 JSON，用于业务自定义标记）和用户级模型倍率。
1. **查看或编辑详情**：从列表进入用户详情，核对预算和关联密钥；在 **Charged cost factors** 中选择目录模型并填写倍率。
1. **发放密钥**：在 [API 密钥管理](/zh/docs/guides/api-keys/) 中为该用户创建密钥，或使用「外部身份」方式在创建密钥时一并解析用户。
</Steps>

## 用户级模型折扣

用户级倍率会在路由的用户计费金额之后应用：

> **最终用户费用 = 目录标准价 × 路由用户计费倍率（含分时覆盖）× 用户模型倍率**

| 倍率 | 常见含义 |
|------|----------|
| `1` | 保持路由计算出的价格 |
| `0.8` | 八折 |
| `0.5` | 五折 |
| `0` | 该用户使用此模型时不计费 |

未添加的模型保持原价。倍率只改变最终用户费用和预算消耗，不改变模型目录价或供应成本；适用于大语言模型、图片和音频，不适用于独立定价的智能体工具。

通过管理接口自动维护时，字段名为 `charged_cost_factors`，形状为 `{ "<模型 ID>": 倍率 }`。不存在的模型、负数和错误格式会被拒绝；写入 `null` 或空对象可清空已有设置。

## 与业务门户配合

你的服务端可在用户注册成功后，通过管理接口创建或更新网关用户、设置模型折扣并下发密钥；环境变量与调用边界见 [系统集成](/zh/docs/guides/integration/)，接口索引见 [GitHub 技术参考](/zh/docs/github-reference/)。
