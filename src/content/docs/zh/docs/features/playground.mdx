调试台（Playground）用于验证**单个上游是否可用**。它不经过用户计费路径，不扣用户额度、不写用户请求日志，也不验证完整的路由策略和故障转移。真实上游仍可能收取费用。

## 操作路径

1. 选择一条上游路由，确认协议、操作和上游模型名。
2. 载入对话、Responses、图片、音频或向量样例，再调整请求体与需要的请求头。
3. 发送并查看状态、响应、流式事件或多模态结果。
4. 修改配置后重新测试，避免沿用旧配置的成功结果。
5. 转到[模拟器](/zh/docs/features/simulator/)验证真实用户、路由、计费与日志。

![向量调试样例](/screenshots/v2-15-0-embedding-playground.webp)

路由编辑器也支持测试尚未保存的目标配置，测试不会替你保存路由。Tools 模式直连已配置的 REST 引擎；MCP 的目录与真实工具调用请按[MCP 指南](/zh/docs/guides/mcp/)验证。

## 实时音频

支持的实时识别路由可使用浏览器麦克风；先确认浏览器授权与模型对应的原生 WebSocket 操作。不是所有音频模型都能用同一实时入口。
