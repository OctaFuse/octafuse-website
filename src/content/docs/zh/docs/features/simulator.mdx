模拟器（Simulator）在浏览器中向你的代理服务发送真实请求。使用测试用户密钥，可完整验证用户鉴权、路由、额度、故障转移和记账。

## 验证步骤

1. 填入代理服务根地址和有效用户 API 密钥。
2. 选择客户端模型、路由组及对应入口；支持的类型包含对话、图片、音频、向量和 REST 工具。
3. 编辑对应协议的请求并发送。
4. 查看响应后，到[请求日志](/zh/docs/guides/request-logs/)找到这次调用，检查上游尝试、用量和记账。
5. 用用户额度与审计记录核对扣减结果。

![按模型和入口选择真实代理请求](/screenshots/v2-6-0-simulator-routing-target.webp)

发送期间模拟器会锁定连接和目标，避免请求与配置错位；请求仍会产生真实的计费和日志。

模拟器按**客户端入口**构造请求，而不是照最终上游协议发送。例如，OpenAI Images 经过适配器转到 Gemini，上游转换由网关完成。

## 与调试台结果不同时

优先检查用户与密钥状态、可用额度、RPM、模型 ID、路由组及启用入口。调试台成功只证明单个上游可用，不证明用户侧调用条件都已满足。

密钥会在你的浏览器内用于请求，使用受信任环境与专用测试凭证；共享设备使用后清理保存状态。MCP 客户端接入请使用[MCP 指南](/zh/docs/guides/mcp/)。
