本页做一件事：按 **默认推荐的 Cloudflare 路径** 把 OctaFuse 跑起来，并能打开管理台。个人与小流量通常可在 Workers / D1 **免费额度**内完成部署与日常使用。

更细的供应商、路由和密钥配置方法见 **[使用指南](/zh/docs/guides/providers/)**。不用 Cloudflare 时见 [Docker 部署](/zh/docs/deploy/docker/)。

<Aside type="note" title="命令所在仓库">
	以下命令在 **[octafuse-gateway](https://github.com/OctaFuse/octafuse-gateway)** 仓库**根目录**执行。
</Aside>

## 1. 本机启动（本地 D1）

### 先决条件

- **Node.js 20+**、npm。
- 无需 Cloudflare 账号。

### 克隆并启动

```bash
git clone https://github.com/OctaFuse/octafuse-gateway.git
cd octafuse-gateway
npm install
npm run db:migrate
npm run dev:proxy
```

另开终端：

```bash
npm run dev:admin
```

| 服务 | 地址 / 位置 |
|------|-------------|
| 代理服务（Proxy） | `http://127.0.0.1:8787` |
| 管理后台（Admin） | `http://127.0.0.1:8789` |
| 控制台登录 | `admin` / `admin`（本地默认；首次 `dev:admin` 会自动生成 `packages/admin/.dev.vars`） |
| 本地 D1 | `./.wrangler/state` |
| 管理 API Bearer 密钥 | `sk-dev-admin-key`（管理 API，不是网页密码） |

健康检查：

```bash
curl -sS http://127.0.0.1:8787/health
```

## 2. 部署到 Cloudflare

前置：Cloudflare 账号，本机已 `npx wrangler login`。

```bash
npx wrangler login
npm run bootstrap:cloudflare
```

完成后按终端提示核对 `GATEWAY_URL` / `GATEWAY_MASTER_URL`，并用 `GET $GATEWAY_URL/health` 验证。完整步骤与发版见 [Cloudflare Workers 部署](/zh/docs/deploy/cloudflare/)。

## 登录管理台

1. 本地打开 **`http://127.0.0.1:8789`**（上云后使用管理后台地址）。
2. 本地默认账号：**`admin` / `admin`**（仅本机；可改 `packages/admin/.dev.vars`）。上云时使用 bootstrap 设置的 `ADMIN_PASSWORD`。Docker 本地一键体验默认是 `admin` / `changeme`，见 [Docker 部署](/zh/docs/deploy/docker/)。

## 建议的下一步（使用指南顺序）

<Steps>
1. [供应商（Providers）配置](/zh/docs/guides/providers/) — 接入上游模型服务
1. [模型（Models）配置](/zh/docs/guides/models/) — 维护网关识别的模型目录
1. [路由（Routes）配置](/zh/docs/guides/routing/) — 用请求入口（Request Surface）→ 路由池（Route Pool）→ 上游目标（Upstream Target）把客户端 `model` 与 `operation` 映射到上游
1. [智能体工具（Agent Tools）](/zh/docs/guides/tools/)（可选）— 配置网页搜索（Web Search）、网页抓取（Web Fetch）和深度搜索（Web Deep Search）的启用引擎
1. [用户（Users）管理](/zh/docs/guides/users/)与 [API 密钥（API Keys）管理](/zh/docs/guides/api-keys/) — 确定谁可以调用以及额度多少
</Steps>

## 可选：立刻打一条测试请求

在管理台里配好**供应商、模型、请求入口、路由池、上游目标和 API 密钥**后，将密钥与 `model` 换成真实值：

```bash
curl -sS http://127.0.0.1:8787/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"your-route-model","messages":[{"role":"user","content":"Hello"}]}'
```

上云后把主机换成你的代理服务地址。
