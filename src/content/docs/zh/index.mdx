**把多家 AI 服务接进一个可控入口。** OctaFuse 统一管理模型和工具的接入、路由、用户额度与调用记录。应用使用网关地址和用户密钥；供应商、备用路由、价格和访问控制在管理后台维护。

## 你可以用它做什么

<CardGrid>
  <Card title="统一模型与工具入口" icon="puzzle">对话、Responses、图片、语音和向量按对应协议接入。REST 工具与远程 MCP 服务集中管理，按需为 MCP 客户端启用 OAuth 授权。</Card>
  <Card title="让调用持续可用" icon="random">按优先级、权重和四种路由策略分配请求。供应商粘性保持成功上游的连续性，故障转移和熔断处理不可用目标。</Card>
  <Card title="给每个用户清楚的额度" icon="padlock">周期额度与永久额度分开管理，支持用户与密钥限流、按模型和路由组设置折扣。供应成本、目录标准价和用户收费分别记录。</Card>
  <Card title="看懂每次请求" icon="magnifier">从请求入站到路由、上游尝试、响应和记账，沿流程与时间线排查故障；结合用量、成本、缓存和可靠性分析调整配置。</Card>
  <Card title="把新服务接进现有应用" icon="laptop">通过模型 ID、协议入口和显式适配器管理上游差异。静态预设便于导入，模型与供应商可逐项比较官方目录更新。</Card>
  <Card title="运行在自己的环境" icon="rocket">使用 Docker + Postgres / MySQL，或 Cloudflare Workers + D1。通过管理 API 对接自己的业务门户，自动开通用户、发放密钥与加额。</Card>
</CardGrid>

## 选择适合你的使用方式

- **个人开发与工具链**：集中配置 IDE、CLI 和脚本使用的模型与工具，准备备用上游。
- **团队与 AI 应用**：给成员、项目或客户独立凭证，按额度、限流与日志管理调用。
- **Agent 与工具平台**：接入 REST 引擎和远程 MCP，审核工具目录并管理调用价格。
- **业务门户与 API 服务**：通过管理接口开通用户、分发额度、设置折扣并查询用量。
