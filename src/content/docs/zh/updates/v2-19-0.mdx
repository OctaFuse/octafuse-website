OctaFuse Gateway 2.19.0 的重点是管理后台：统一了视觉风格，重新整理了路由、模型、供应商、日志、用户和 MCP 等页面的筛选、详情与表单，并修复了一批查询与跳转问题。

模型与供应商目录同步更新，新增 23 个模型预设，其中包括 Claude Fable 5.2、智谱 GLM-5V-Turbo、混元 HY4 和 GPT Image 2.6。

**这一版没有数据库迁移，也没有新增或改名的环境变量与 `system_config` 键。** 数据面（Proxy 与 Core）只有两处改动：Qwen-Audio 语音合成适配器匹配，以及 Command Code 额度查询。升级时需要留意的是后台入口的位置变化，以及新目录项需要手工导入。

## 01｜管理后台：统一风格，整理各页面的交互

这一版以界面与交互整理为主，目标是让常用操作更直接、信息层次更清晰。

- **统一风格**：浅灰工作区、白色面板、黑色主操作；标题、筛选、表格和状态的层次重新整理，功能区充分利用可用宽度。登录页与导航使用新的蓝青色 Octafuse 标识。
- **弹窗与表单**：编辑、详情、导入、定价和确认弹窗统一了布局与键盘焦点；表单补齐未保存草稿的退出确认。页面适配窄屏、中英日韩四种语言以及「减少动态效果」设置。
- **顶栏与导航**：语言切换移到右上角，与文档入口放在一起。

![管理后台仪表盘：概览卡片、趋势分析、实时概况、用量排行与 Token 汇总、近期活动](/screenshots/v2-19-0-dashboard.webp)

*统一风格后的仪表盘（英文界面，时间范围为近 30 天）。右下方是新增的 Token 汇总和近期活动，用户邮箱已遮盖。*

仪表盘概览卡片改为同排等高，并新增输入、输出和缓存读取的 Token 汇总，还增加了「近期活动」和「实时概况」两个区块。近期活动展示全局最新记录，不随上方时间范围变化；实时概况中的吞吐为近 60 秒数据。

## 02｜入口位置变化

升级后，下面这些入口的位置与旧版不同，其中前两项需要告知团队里的其他管理员。

| 内容 | 2.18.0 | 2.19.0 |
|---|---|---|
| 维护模式 | 侧栏「系统 → 维护模式」 | 「系统 → 配置」中的「维护模式」分区；旧地址会自动跳转 |
| 集成密钥 | 单独的「系统集成」分组 | 归入「系统」分组 |
| 全局配置 | 一页平铺 | 分为「基础设置」「路由与计费」「通知」「维护模式」四个分区，各项仍分别保存 |
| MCP 服务页 | 「客户端接入与授权」 | 「客户端接入」，OAuth 设置与访问令牌仍在这一分区 |
| 目录更新 | 模型页、供应商页的「检查官方更新」 | 统一为「同步」：先比对差异，确认后再应用 |

### 维护模式

维护模式的功能没有变，仍然是在维护期间让推理请求收到 503 提示，健康检查和只读接口不受影响。这一版调整了表单的组织方式：集中展示时长、提示文案和影响范围，并说明维护期间推理请求返回 503、健康检查和只读列表不受影响。

需要留意两点：自定义预计时长必须是正整数分钟；预计时长只用于客户端提示，到时间后**不会**自动结束维护，仍需手动结束。

![「配置」页「维护模式」分区：预计时长、提示文案与影响范围](/screenshots/v2-19-0-config-maintenance.webp)

*维护模式现在位于「配置」页的分区里（英文界面，当前为未开启维护的状态）。预计时长旁的说明写明：时长会展示给客户端，维护仍需手动结束。*

### 目录同步

模型页和供应商页现在统一用「同步」入口。点击后先与官方目录比对，结果集中展示，确认后才会应用。已导入的模型和供应商不会被目录覆盖，价格也默认保留当前值。同一页面里移除了重复的状态展示。

![模型页「与官方目录同步」对话框：按厂商分组，逐字段选择采用官方值或保留当前值](/screenshots/v2-19-0-model-sync.webp)

*点击「同步」后先比对差异（英文界面）。页面顶部提示价格默认保留，标签、元数据、路由和价格覆盖不会被修改。*

## 03｜各页面的主要变化

下面只列用户在日常操作中最容易感知的变化。

- **供应商与模型**：导入和新建集中到标题区。模型页支持按名称、ID、厂商或标签搜索，导入对话框合并了名称与 ID。向量模型只显示输入单价，未配置的定时定价默认收起。
- **路由**：按模型区分请求入口、路由组、供应商和费用对比。低频的筛选、倍率、路径和粘性刷新偏好收进弹窗。页面上的「配置可用」只表示路由和供应商都已启用，**不代表实时健康**。图像和语音的计费单位按实际计费配置展示。
- **调试台与模拟器**：整理了连接、目标、请求和响应的布局，模拟器新增了密钥筛选。请求发送期间，连接与目标会被锁定。
- **用户与 API Keys**：列表聚焦身份、状态和额度，完整用户 ID 移入详情。新建密钥时可以搜索已有用户，也可以手填用户 ID 或使用外部身份；密钥默认掩码展示。
- **请求日志**：常用筛选放在上层，高级条件收在下层。时间选择支持业务时区，可以只设起点或终点，也可以不限时间；快捷范围改成「最近 1 小时」「最近 7 天」这类直接的文字。
- **审计日志**：列表展示事件、身份和额度变动摘要，详情分为概览、字段变更和原始记录三部分，可复制审计 ID。
- **REST 与 MCP 服务**：REST 服务把连接、计费、测试和启用集中在一个弹窗里，保存只提交当前服务，未保存的修改可以还原。MCP 服务页补充了「调用记录」入口。

![请求日志列表：顶部是常用筛选与时间范围，其余条件收进「更多筛选」](/screenshots/v2-19-0-request-logs.webp)

*请求日志列表（英文界面）。常用筛选放在上方，其余条件收进「更多筛选」。`USER · SYSTEM` 列与供应商账号已遮盖。*

## 04｜问题修复

- **日志与查询**：修复请求日志默认日期、清空时间后重新加载，以及历史错误下钻时的时间边界；避免过期的查询结果覆盖当前结果。修复了调用记录查询覆盖、MCP 下钻范围丢失和历史身份筛选问题。
- **状态与错误处理**：修复维护状态轮询覆盖刚写入的结果的问题，以及模拟器自动生成的 `task_id` 被误判为手动编辑。REST 与 MCP 加载失败时提供重试入口；OAuth 配置加载成功前禁止写入。
- **日志兼容**：上游返回 HTML 错误页时，列表只显示摘要，完整内容保留在请求详情；审计详情兼容缺失的快照和非对象的扩展数据。
- **控件与弹窗**：统一下拉箭头的位置，补齐折叠说明的键盘导航、用户活动详情的关闭和滚动布局。

## 05｜模型与供应商目录

相比 2.18.0，目录新增了 23 个模型预设。已导入的模型不会被覆盖，导入也不会自动挂路由；新模型需要手工导入并配置路由。

### 本版重点

| 模型 | 说明 |
|---|---|
| **Claude Fable 5.2** | 新增 `claude-fable-5-2`（2026-11-09），上下文 1M、最大输出 128K，输入支持文本、图片与文件。标准刊例价输入 $8、输出 $40、5 分钟缓存写入 $10、缓存读取 $0.20 / 百万 tokens，不含 Fast 模式与 Batch 折扣。人民币价为美元刊例 ×7 的占位值，使用前请核对。 |
| **智谱 GLM-5V-Turbo** | 新增 `glm-5v-turbo`，上下文 200K、最大输出 128K，输入为文本、图像、视频与文件。人民币刊例按输入长度分两档（输入长度不足 32K：输入 ¥5、输出 ¥22、缓存命中 ¥1.2；32K 及以上：¥7 / ¥26 / ¥1.8，均为每百万 tokens）。官方没有公布美元价，目录**不含美元价**。 |
| **混元 HY4** | 新增 `hy4` 正式版（2026-11-04），上下文 1M、最大输出 64K，支持文本与图片输入，在 TokenHub 原生支持 Chat、Responses 和 Anthropic Messages。刊例价沿用 `hy4-preview`：输入 ¥6、输出 ¥18、缓存命中 ¥0.3 / 百万 tokens。TokenHub 限时五折活动不计入目录价。 |
| **GPT Image 2.6** | 新增 `gpt-image-2.6-flare` 与 `gpt-image-2.6-sunburst`（2026-11-04）。刊例价与 GPT Image 2.5 相同；人民币价为美元 ×7 的占位值。仅支持 Images API，不能作为 Responses 或 Chat Completions 的主模型。新增的 `complexity`、`svg` / `gif` 输出和 GIF 帧参数作为额外字段转发，不要写成路由默认值。 |

### 腾讯云 TokenHub 模板

按量模板改用广州站点 `tokenhub.tencentmaas.com`，支持 Chat、Responses、Embeddings 和 Anthropic Messages。个人版 Token Plan 使用 `/plan/v3` 与 `/plan/anthropic`，并补充了 Responses。通用套餐与 Hy 套餐共用地址及 `sk-tp-` 开头的 Key；新加坡站 `tokenhub-intl.tencentmaas.com` 需要单独配置。

### 退役日期与上下文修正

- **Gemini 2.5**：`gemini-2.5-pro` 与 `gemini-2.5-flash` 已写入 Gemini API 公布的停服日 **2026-12-01**。该日起 Google 会把请求分别自动改路由到 `gemini-3.8-flash` 与 `gemini-3.5-flash-lite`，请提前检查相关路由。
- **其他退役日期**：`gpt-image-1.5` 与 `gpt-image-1-mini` 为 2026-12-01，`qwen3.5-plus` 为 2027-01-19。只记录官方停服日，不影响路由与计费。
- **上下文与最大输出**：MiniMax M2.5、M2.7、M2.7 Highspeed 统一为 200000；`hy4-preview`、豆包 Seed 2.1 Pro / Lite（260915）以及 MiMo V2 Pro、V2.5 Pro、V2.5 统一为 1000000，按 K = 1000、M = 1000000 记录。

## 06｜其他更新

- **Qwen-Audio 语音合成**：`dashscope-tts-qwen-audio` 及 DashScope 的 `audio.speech`、`audio.speech.stream` 透传支持 `qwen-audio-3.1-tts-next` 与 `qwen-audio-3.1-tts-plus`，预设计费不变。
- **Command Code 额度**：补充月度包含额度，订阅或用量查询失败时不影响余额、5 小时和每周窗口的展示。

## 升级须知

**从 2.18.0 升级到 2.19.0 不需要执行数据库迁移。** 从更早版本升级时，仍需补齐其间尚未应用的迁移。

1. 将 Proxy、Admin 和 migrate 三个镜像更新到同一版本，再滚动重启。
2. 升级后抽查路由、请求日志、调试台和模拟器，确认新界面下的筛选与跳转符合预期。

升级时还需留意：

- **后台入口**：维护模式和集成密钥的位置变了，见上文「入口位置变化」。旧的维护模式地址会跳转到新位置。
- **新目录项**：Claude Fable 5.2、GLM-5V-Turbo、混元 HY4、GPT Image 2.6 等需要手工导入并配置路由。目录更新不会覆盖已导入的模型与供应商。
- **Gemini 2.5**：2026-12-01 起由 Google 自动改路由，请提前检查相关路由。

完整变更见 [GitHub Release v2.19.0](https://github.com/OctaFuse/octafuse-gateway/releases/tag/v2.19.0) 和 [更新记录](https://github.com/OctaFuse/octafuse-gateway/blob/v2.19.0/CHANGELOG.md)。
